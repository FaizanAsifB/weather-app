## About the project

![Weather App Preview](https://github.com/FaizanAsifB/Portfolio/blob/main/src/content/projects/project-images/weather-wide.jpg?raw=true)

The Weather App aims to provide users with current weather conditions and beautiful background images based on their selected locations. Designed for simplicity and aesthetic appeal, the app allows users to easily access weather forecasts, including temperature, humidity, wind speed, and precipitation, for any location worldwide. It leverages geolocation functionality to retrieve weather data based on the user's current location, enhancing convenience and usability.

The development of the Weather App posed several challenges. As my first solo project, I navigated the complexities of integrating weather data from an external API and implementing geolocation functionality. These tasks demanded the application of programming skills acquired from tutorials and courses, requiring meticulous planning and adept troubleshooting to ensure seamless integration and functionality.

To address these challenges, I applied learned skills and knowledge to manage the project independently. I deepened my understanding of API endpoints, data parsing, and error handling to effectively integrate weather data. Additionally, implementing dynamic background image retrieval based on user-selected locations involved integrating advanced API functionalities and refining data handling processes to ensure users receive visually immersive and contextually relevant weather updates.

## Installation

To install and run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/FaizanAsifB/weather-app.git
   cd weather-app
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up environment variables:

   - Copy the `.env-example` file and rename it to `.env`.
   - Define the required environment variables in the `.env` file.

4. Run the development server:

   ```bash
   npm start
   ```

   - The development server runs on port 1234.

   - Open [http://localhost:1234](http://localhost:1234) in your browser to play the game.
